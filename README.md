# 🔥 Пепел Мастера

Личная игра для iPhone.

**Скачать последнюю сборку (.ipa):** раздел *Releases* → `AshMaster.ipa`
или прямая ссылка: `https://github.com/takosta/PEPEL/releases/latest/download/AshMaster.ipa`

Подпиши файл своим сертификатом (ESign / Feather / Scarlet и т.п.) и установи.

> ⚠️ Игроку: не открывай папку `dev/` — там исходники и сценарий со спойлерами.

Каждый пуш в `main` автоматически собирает новую `.ipa` через GitHub Actions.
